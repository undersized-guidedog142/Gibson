## 🖥️ What Is Gibson?

Gibson transforms your Mac's screen saver into a retro, hacker-film-style dashboard. It looks like something straight out of a 1990s cyberpunk movie—green text, scanning lines, and real-time data from your computer.

The name comes from the fictional hacker group in the movie *Hackers* (1995) and pays homage to William Gibson, the father of cyberpunk.

## 👀 What Does It Show?

Gibson displays live system telemetry—real information from your Mac—in a cool, retro interface. You'll see:

<b>📊 System Performance</b>
- CPU usage
- Memory usage
- Disk activity
- Network traffic

<b>🖥️ Dashboard Elements</b>
- Terminal-style scrolling text
- Animated data streams
- CRT monitor effect (scan lines, glow)
- Random hacker-style sequences

<b>Step 3: Install the Screen Saver</b>
- Open the extracted folder
- Double-click the <code>Gibson.saver</code> file
- A message will ask if you want to install for all users or just for you
- Choose your preference (usually "Install for current user" is fine)

<b>Step 4: Activate the Screen Saver</b>
- Go to <b>System Settings</b> > <b>Screen Saver</b> (or <b>Desktop & Screen Saver</b> on older macOS)
- Find <b>Gibson</b> in the list
- Click on it
- Adjust settings if available (like text color or refresh rate)
- That's it! Your Mac now has a cyberpunk screen saver

## 🔧 Customization

Gibson comes with several built-in options to change the look:
<b>Color Themes:</b> Green (classic), Amber, Blue, or White
<b>Data Rate:</b> How fast telemetry updates
<b>Scanline Effect:</b> Strength of CRT visual effect
<b>Big Mode:</b> Enlarged text for smaller screens

## 💻 Advanced Usage

If you're more technical, you can tweak Gibson's settings file manually. Look for <code>com.gibson.screensaver.plist</code> in your Preferences folder. This is completely optional.

## 🛠️ Troubleshooting

<b>Gibson won't appear in Screen Saver list:</b>
- Make sure you installed the <code>.saver</code> file correctly
- Try restarting your Mac
- Go to <b>System Settings</b> > <b>Privacy & Security</b> and allow it if blocked

<b>No telemetry shows up:</b>
- Gibson needs permission to access system data
- Check <b>System Settings</b> > <b>Privacy & Security</b> > <b>Files and Folders</b> and allow Gibson

<b>Performance issues:</b>
- Reduce the animation speed in Gibson's settings
- Turn off scanlines for more performance
